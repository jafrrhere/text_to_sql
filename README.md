# Text-to-SQL

Text-to-SQL is a local AI-powered chatbot that lets users ask questions about a SQL database in natural language. It uses an Ollama language model to generate SQLite queries, executes permitted read-only queries against the database, and displays the results in a chat interface.

## Features

- **Natural-language queries:** Ask questions without writing SQL manually.
- **Local language model:** Uses Ollama with `qwen2.5:3b`.
- **LangChain integration:** Supplies the database schema to the model when generating SQL.
- **SQLite database:** Uses `Chinook.db`.
- **Results in chat:** Displays query results in a table.
- **SQL inspection:** Expand a section to view the generated SQL.
- **Chat interface:** Streamlit chat messages, suggested questions, and a sidebar.
- **Session-based chat history:** Keeps messages and recent chats in the active Streamlit session.
- **Read-only safeguards:** Opens SQLite in read-only mode, restricts queries to `SELECT` or `WITH`, and uses a SQLite authorizer to block selected database-changing actions.

## Prerequisites

1. Python 3.10 or newer, compatible with your installed packages.
2. [Ollama](https://ollama.com/) installed and running.
3. The `qwen2.5:3b` model downloaded in Ollama.
4. Project files including `app.py` and `Chinook.db`.

## Setup

### 1. Open the project

Open the existing project folder in VS Code, or clone your repository:

```bash
git clone <your-repository-url>
cd <your-project-folder>
```

### 2. Create and activate a virtual environment (recommended)

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, use Command Prompt:

```bat
.venv\Scripts\activate.bat
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
python -m pip install streamlit langchain langchain-community langchain-core langchain-ollama sqlalchemy pandas
```

Alternatively, create a `requirements.txt` containing:

```text
streamlit
langchain
langchain-community
langchain-core
langchain-ollama
sqlalchemy
pandas
```

Then install it:

```bash
python -m pip install -r requirements.txt
```

### 4. Download the Ollama model

```bash
ollama pull qwen2.5:3b
ollama list
```

Ensure Ollama is running before launching the app.

### 5. Check the database file

Confirm that `Chinook.db` is in the same folder as `app.py`. The app expects that filename by default.

## Run the Application

With your virtual environment activated, run this command from the project directory:

```bash
streamlit run app.py
```

Streamlit will show a local URL, usually:

```text
http://localhost:8501
```

Open it in your browser.

## How It Works

1. The user enters a natural-language question in the Streamlit chat interface.
2. LangChain provides the database schema and question to the Ollama model.
3. The model generates a SQLite query.
4. The application checks the query and executes it against `Chinook.db` using a read-only SQLite connection and an authorizer.
5. Results appear in the conversation, and the generated SQL can be inspected.
6. Chat messages and recent chat selections are stored in Streamlit session state.

## Example Questions

- `How many tracks are in the database?`
- `Show me 10 random artists.`
- `Which artists have the most albums?`
- `Show the 5 most expensive tracks.`

The exact answer depends on the contents of `Chinook.db` and the SQL generated by the model.

## Troubleshooting

### Ollama model not found

```bash
ollama pull qwen2.5:3b
ollama list
```

Ensure the model name in `app.py` matches the installed model.

### Database not found

Make sure `Chinook.db` is next to `app.py`. Check the filename and spelling.

### Streamlit command not found

Activate your virtual environment and install Streamlit:

```bash
python -m pip install streamlit
```

Then run:

```bash
python -m streamlit run app.py
```

### SQL generation or query errors

- Check that Ollama is running.
- Try a simpler question using tables and columns that exist in the database.
- Expand **View generated SQL** to inspect the query.
- Check the terminal for the full error message.

### Port 8501 is already in use

```bash
streamlit run app.py --server.port 8502
```

Then open `http://localhost:8502`.

## Limitations

- Response speed depends on your computer's hardware because the model runs locally.
- Generated SQL may be incorrect, even when the model receives the schema.
- Chat history is held in Streamlit session state, not a persistent database, and may disappear when the session resets.
- This is a learning/demo project, not a hardened production service. SQL checks and the SQLite authorizer reduce risk but are not a complete security boundary for untrusted users or arbitrary queries.
- To use another database, update the database path and ensure the prompt receives its schema.
